# 소아 수부 X-ray 골연령 자동 판독 시스템

수부 X-ray 한 장에서 골연령(개월)을 회귀 예측하는 단일 모델입니다.
GP atlas 육안 대조 방식의 판독자 간 편차와 건당 수 분의 판독 시간을 자동화하는 것이 목표였습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026.07 ~ 2026.08 |
| 최종 성능 | **Test MAE 4.05개월** / Val MAE 5.81개월 |
| 데이터 | train 12,611장 / val 1,425장 / test 200장 |
| 핵심 스택 | PyTorch, ConvNeXt-Tiny, YOLO, Segmentation, LDL, FiLM, TTA |

📄 **[포트폴리오 PDF 보기](./docs/portfolio.pdf)**

---

## 파이프라인

손 검출(YOLO) → 세그멘테이션 정렬 → 강도 정규화(1~99 퍼센타일) → 레터박스(768×512)
→ ConvNeXt-Tiny + FiLM 성별 조건화 → LDL 240-bin → 5각 TTA 후처리

## 성능 개선 이력

| 버전 | 변경점 | Test MAE |
|---|---|---|
| B-v5 | Attention + LDL 재현 (Xception) | 7.69 |
| B-v6 | R2 채널을 논문 방식으로 복원 | 6.48 |
| B-v7 | 마커 억제 + 회전 정렬 + 기하 증강 | 5.93 |
| C-v5 | 단일 회귀 전환 · ConvNeXt-Tiny + EMA | 4.26 |
| C-v6 | 768×512 + 도메인 증강 + 5각 TTA | 4.12 |
| C-v11 | 성별 조건화 | 4.11 |
| **D-v11** | **YOLO + Segmentation 정렬 크롭** | **4.05** |

## 핵심 의사결정

**1. 규칙 기반 크롭 폐기 → 학습 기반 검출**
임계값·윤곽 기반 크롭이 촬영 밝기·각도·배경 편차로 빈번히 실패. 손 bbox를 직접 라벨링해 YOLO 검출 모델을 학습시켜 검출·정렬을 전부 학습 기반으로 전환했습니다.

**2. Attention 논문 구조 폐기 → 단일 회귀 전환**
CAM 기반으로 R1·R2 ROI를 추출하는 논문 구조를 구현했으나, ROI가 엉뚱한 위치에 잡히는 문제가 있었고 보정 후에도 논문 수준(4.30)과 격차가 컸습니다. ROI 집계 자체를 폐기하고 백본을 ConvNeXt-Tiny로 교체하는 단일 회귀 구조로 전환해 5.93 → 4.11로 개선했습니다.

**3. LDL(Label Distribution Learning) 채택**
골연령 정답은 판독자 간 편차를 포함한 확률적 라벨입니다. 점 추정 대신 가우시안(δ=15) 분포를 학습하고 기대값을 출력하는 방식을 택했고, EMA(0.9995)와 5각 TTA로 test MAE를 각각 −0.09 / −0.06개월 추가로 안정화했습니다.

**4. Segmentation 기반 정렬 크롭 (최종)**
옆으로 누운 손을 세로축과 수직이 되도록 정렬하는 크롭을 YOLO + Segmentation으로 구축했습니다. MAE 차이는 신뢰구간 안이지만 RMSE가 -0.19 줄어 큰 오차 사례가 감소했습니다.
